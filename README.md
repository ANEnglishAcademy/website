# AN English Academy Elementor Page Kit

This repository stores the locked workflow, style rules, and copy/code blocks for AN English Academy product pages built in WordPress Elementor.

## How To Use

Each product page is built section by section.

For each section:

1. Open the `.css` file.
2. Paste it into the Elementor container's **Custom CSS** field.
3. Open the matching `.html` file.
4. Paste it into an **HTML widget** inside the same container.

Do not paste `<style>` tags into Elementor Custom CSS.

## Locked Workflow

- One Elementor container per section.
- One HTML widget inside each container.
- Minified CSS and HTML for final delivery.
- Same visual system across all product pages.
- Buttons point to Telegram by default.
- SEO-friendly copy, but not bulky.
- No unnecessary JavaScript.
