# Locked Elementor Workflow

This is the locked process for all AN English Academy product pages.

## Delivery Format

Codex gives each page one section at a time:

1. Short preview.
2. Minified CSS for Elementor container Custom CSS.
3. Minified HTML for the HTML widget.
4. Short explanation when needed.

## Rules

- No huge all-in-one file by default.
- No `<style>` tags in Custom CSS.
- CSS variables are scoped to the section class.
- Keep each section self-contained.
- Use SEO keywords naturally in subtitles, headings, card copy, FAQ, and alt text.
- Keep product H1 clean if the SEO version is too bulky.
- Use `h1` once, `h2` for sections, `h3` for card titles.
- Use CSS animations only with `opacity` and `transform`.
- Include `prefers-reduced-motion`.
- No unnecessary JavaScript.

## Visual Direction

- Clean, bright, branded, modern.
- Premium but not stiff.
- Uses violet, pink, yellow, white and soft lavender.
- Rounded sections and cards.
- Strong typography, not oversized walls of text.
